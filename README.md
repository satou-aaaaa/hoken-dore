# どの保険？（hoken-dore）

困ったときの場面（病気で病院へ・仕事中のけが・仕事をなくした・年をとった・介護が要る など）を読んで、どの社会保険（健康保険・年金・雇用保険・労災保険・介護保険）が支えるかを当てる1日5問の学習ゲーム。正解したら「保険料はだれが払う？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/hoken-dore/>

- 中身は、厚生労働省・ハローワーク・全国健康保険協会（協会けんぽ）・日本年金機構の公式ページに書いてあることだけです（2026-11-17 に読みました。URL は `data.js` の `SRC`）。
- 場面は会社で働く人の場合です。国民健康保険・国民年金の人は、保険料の払い方がちがいます。もらえる額や手続きは扱いません。
- このゲームは社会保険のしくみを知る練習です。公式の情報の代わりではありません。保険の相談や手続きは、会社・年金事務所・ハローワーク・労働基準監督署・市区町村の窓口で確かめてください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
